ASD 文档 ​

这是 ASD (GitHub Release 下载工具) 的官方文档网站。

开发 ​

安装依赖 ​

bash
npm install

本地开发 ​

bash
npm run docs:dev

开发服务器将在 http://localhost:5173 上运行。

构建文档 ​

bash
npm run docs:build

本地预览构建结果 ​

bash
npm run docs:serve
